# Text Tools

Run Format text in the installed details, or explicitly enable Clean speech output to process final speech text. The processor is off by default. Configuration supports space cleanup and an optional prefix; the command stores only an invocation counter, never input text. No network, model or account access is used. Disabling/uninstalling cancels active requests and removes hooks; private data is retained for reinstall.

Requires the unreleased EchoBird product SDK (`0.1-draft`). Shared portable source; Windows development verification does not establish macOS/Linux native verification.
