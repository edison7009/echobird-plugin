# Ocean Theme

Apply Ocean in the installed plugin details. Light/dark follows EchoBird’s mode. Disable or uninstall to restore the built-in palette; your built-in color selection is retained. No background code, files, network or account access is requested.

Requires the unreleased EchoBird product SDK (`0.1-draft`). Shared portable source; Windows development verification does not establish macOS/Linux native verification.
